# BYTE BACK 방어전 | 내 자료실

이 프로젝트는 SKT ALEPH 방어전 실습을 위한 가상 자료실 애플리케이션입니다.  
포함된 메모 기록은 모두 실습을 위한 가상 데이터이며, 실제 개인정보나 비밀값은 포함되지 않습니다.

---

## 📌 현재 단계: 2단계 (자료를 코드 밖으로 이동)

### 1. 동작 방식
* **자료의 데이터베이스화**: 기존 정적 파일(`data.json`)에 들어있던 가상 메모들을 외부 데이터베이스(Supabase `notes` 테이블)로 이전했습니다.
* **서버리스 함수 연동**: 웹 메인 화면(`/`)은 정적 파일 대신 Vercel 서버 함수(`/api/notes`)를 호출하여 가상 메모 4건을 동적으로 읽어옵니다.
* **보안 관리**: 데이터베이스 접근을 위한 환경변수(`SUPABASE_URL`, `SUPABASE_SECRET_KEY`)는 서버 환경변수에서만 안전하게 참조되며, 브라우저 파일, 네트워크 응답, 로그 어디에도 노출되지 않습니다.
* **정적 파일 비우기**: `/data.json`은 빈 배열(`"notes": []`)로 유지되어 정적 파일을 통한 자료 노출을 방지합니다.

---

## ⚠️ 현재의 보안 약점 (공개 주소)

* **약점 내용**: 자료를 코드와 정적 파일 밖으로 분리하는 데 성공했으나, 현재 `/api/notes` 서버 함수는 인증(로그인)이나 접근 통제 검문소가 적용되어 있지 않은 **공개 주소(Public endpoint)**입니다.
* **영향**: 엔드포인트 주소를 알고 있는 외부 방문자는 로그인하지 않은 상태에서도 `/api/notes`를 직접 호출하여 가상 메모 목록을 열람할 수 있습니다.
* **대응 계획**: 다음 단계에서 사용자 인증(Identity Provider) 및 인가 검문소 정책을 적용하여 비인가자의 접근을 차단할 예정입니다.
